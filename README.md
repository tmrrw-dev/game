# SATOSHI: DIGITAL GOLD — v0.2.1 (исправление запуска и клика)

## Быстрый запуск на Windows
1. Установи Node.js LTS: https://nodejs.org/
2. Распакуй ZIP в отдельную папку.
3. Дважды нажми `start.bat`.
4. При первом запуске дождись установки зависимостей.
5. Открой в браузере `http://localhost:3000`.

**Важно:** не открывай `public/index.html` двойным щелчком. Версия 0.2 использует сервер и API; без запущенного сервера клик не начисляет SAT.

Для локальной игры `.env` создаётся автоматически из `.env.example`. Это режим разработки. Перед публикацией настрой `BOT_TOKEN` и `DEV_MODE=false`.

# SATOSHI: DIGITAL GOLD — v0.2

## Что нового
- Серверная экономика: SAT и покупки больше не хранятся только в браузере.
- SQLite база игроков.
- Авторизация Telegram Mini App через проверку `initData` на сервере.
- Серверные клики, покупки и пассивная добыча.
- Офлайн-начисление ограничено 8 часами.
- Простой рейтинг по скорости добычи.

## Локальный запуск
1. Установите Node.js 20 или новее.
2. Распакуйте архив.
3. В папке проекта выполните:
   ```bash
   npm install
   ```
4. Скопируйте `.env.example` в `.env`.
5. Для локальной проверки оставьте `DEV_MODE=true`.
6. Запустите:
   ```bash
   npm start
   ```
7. Откройте `http://localhost:3000`.

## Подключение Telegram
- Создайте бота через @BotFather и получите токен.
- Укажите токен в `BOT_TOKEN`.
- Для публичного запуска обязательно установите `DEV_MODE=false`.
- Разместите приложение на HTTPS-хостинге.
- Привяжите HTTPS URL к Mini App через BotFather.

## Важно
- Не публикуйте `.env` и токен бота.
- `DEV_MODE=true` предназначен только для локального тестирования: все локальные посетители используют один demo-профиль.
- GRAM пока отображается как нулевой демонстрационный баланс. Реальная покупка Jetton, подтверждение on-chain транзакций и выдача оборудования ещё не реализованы.
- SAT — внутриигровая валюта, не BTC и не обещание финансовой доходности.
- Перед публичным запуском нужны дополнительные меры: HTTPS, rate limiting, защита от повторов запросов, резервное копирование SQLite и тестирование Telegram auth.
